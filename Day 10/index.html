What is CSS?

CSS stands for cascading style sheets.It is fundamental rule-based style sheets that is used to control the visual representation , layout and formatting of the web pages written in HTML.

Three ways to add CSS in HTML:

  1. Inline CSS
  2. Internal CSS
  3. External CSS

Inline CSS:

Inline CSS means that we use a style attibute inside the element to style that element and it is not a good practice to add CSS in HTML.

Internal CSS:

Internal CSS means we use style tag in the head section after title to add CSS in HTML. We use internal CSS when we are working on a small web page and we have to style a very little.

External CSS:

External CSS means we write all of our CSS code in a separate CSS file and then link that CSS file in HTML to add CSS styling. We use external CSS when we are working on a big website or production level website where we have to style at a large level.
