What is HTML Entity?

HTML entities are the spacial sequence of characters that is used to safely display reserved characters,invisible spacing and those characters that are not found on keyborad like euro,infinity etc.

For example:

Reserved characters like <>,HTML treats them as the structural tags and does not display the tage in the final output but if you want to display the tags as well then you will use HTML entities.

Syntax Structure:

  1. An ampersent(&) to start
  2. The specific identifier name or numeric code.
  3. A semicolon (;) to close.

HTML entities are:

  1. & lt; = < ,is for less than

  2. & gt; = > , is for greater than

  3. & amp; = & , is for persent sign

  4. & nbsp; = , is for spacing

  5. & quot; = "" ,is for double quotation mark

  6. & copy; = ,is for copyright logo

  7. & euro; = ,is for euro currency symbol

Eaxmple for each entity:

  1. Using & lt;(< ) and & gt;(> )

    Instead of this < p> , use this: & lt;This is paragraph & gt;

    Output:

    <This is a paragraph>

  2. Using & amp;(&)

    It is used to start an entity.

    Output:

    & lt; ,& gt; etc

  3. Using & nbsp;( --)

    Instead of this:

    This is me .... and this is you

    Use this:

    This is me & nbsp; & nbsp; & nbsp; this is you

    Output:

    This is me    this is you

  4. Using & quot;("")

    Once a wise man said& quot;Nothing

    Output:

    Once a wise man siad"Nothing"

  5. Using & copy;(copyright logo)

    & copy;Copyrights are reserved.

    Output:

    © Copyrights are reserved.

Conclusion:

Basically HTML entities are for displaying the characters that are reserved in HTML and those characters that are not found in the keyboard and importantly if you want to display code written in any programmimg language in your HTML document then entities are really helpful.
